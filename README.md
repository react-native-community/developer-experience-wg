# React DevX Working Group

Discussions-only repo for meeting notes around React Developer Experience.

Please navigate to the [Discussions tab](https://github.com/react-native-community/developer-experience-wg/discussions) to view all content.

## How to contribute

Discussions are **read only**, used to coordinate efforts between the React team and [our partners](https://github.com/facebook/react-native/blob/main/ECOSYSTEM.md#partners) and provide a transparent log.

Please use the main [Discussions and Proposals](https://github.com/react-native-community/discussions-and-proposals) repo for raising new discussions.
